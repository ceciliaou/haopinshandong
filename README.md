# 好品山东 · GEO合规智能传播工作台

面向山东农产品与中小企业的营销内容工作台：**生成 → 合规预审 → 传播预判**。

保留原来的 Streamlit 基本页面与操作路径，视觉与能力做了一轮升级；默认使用本地规则引擎，**不配置 API Key 也能完整跑通**。

> 代码仓库：<https://github.com/ceciliaou/haopinshandong>
>
> 在线体验：<https://haopinshandong-bhfdlfwuiqdfko8sn3eafv.streamlit.app/>

## 运行

```powershell
cd D:\projecttext
.\.venv\Scripts\python -m streamlit run app.py
```

打开 http://localhost:8501 。
演示模式：http://localhost:8501/?demo=1 会自动生成一组示例，方便截图。

依赖见 `requirements.txt`（`streamlit`、`openai`）。

## 文件

| 文件 | 作用 |
| --- | --- |
| `app.py` | Streamlit 页面：侧边栏、主题样式、六个页签、交互 |
| `engine.py` | 本地规则引擎：9 类合规词库、本地生成、传播评分 |
| `expander.py` | 素材扩写：品类事实抽取、分品类短语库、长文结构、饱满度评估 |
| `content_gaps.py` | 内容缺口模块：29 个方向、品类加权、覆盖检测、补全提纲 |
| `content.py` | 作品说明与前几轮对话沉淀：设计思路、传播理念、创新点、AI 工具、时间线 |
| `compliance.py` | 兼容旧接口 `check_compliance()`，内部复用 `engine.audit()` |
| `.streamlit/config.toml` | Streamlit 主题色与运行配置 |

## 页面结构

1. **智能生成**：产品名称 + 特点 + 渠道，生成 3 条 ≤80 字文案；选择「全部渠道」时每个渠道各 1 条（共 4 条）；逐条合规分、风险提示、一键合规优化、下载。
2. **素材扩写**：先选产品种类（农产品/食品/美妆/数码/家居/通用），再输入几句原始素材，选择渠道、风格和篇幅；按品类扩写成 400 字左右的完整文案，显示饱满度、采用素材、待补事实，可直接送合规预审。
3. **方向补全**：编辑产品资料和当前广告文案，扫描产地、品种、新鲜、营养、时令、物流、认证、口碑、场景、售后、价格、礼赠等 29 个方向；区分「素材已有」与「需补事实」，直接填写补全句，生成补全文案并立即预审。
4. **合规预审**：粘贴文案，输出合规分、风险等级、命中词、原文标注和逐条建议；带「填入风险示例」。
5. **传播预判**：七维评分、进度条、归因与优化建议。
6. **作品说明**：作品简介、设计思路、传播理念、创新点、AI 工具、从对话到作品的时间线。

## 两种模式

- **本地规则引擎（默认）**：词库、模板、标签、评分全部离线；没有 Key 也能用。
- **AI 增强（可选）**：配置 `SILICONFLOW_API_KEY` 后，可调用 `deepseek-ai/DeepSeek-V3.2` 生成，再回到同一套合规检查；网络或额度异常自动回退本地。

密钥读取顺序：环境变量 → `.env` → `.evn`。页面不会显示密钥，代码中也不再写死 Key。

> 注意：当前 `.evn` 是本机私有的 Key 文件，分发/提交前请删除或改用环境变量，避免密钥泄露。

## 视觉

- 深海军蓝 + 墨绿 + 金色的「山东产地」主题；
- 侧边栏品牌区、首屏 Hero、指标卡、风险卡、时间线；
- 胶囊式页签：当前项深色渐变填充，未选中项浅色悬停，切换状态更明显；
- 方向补全改为两栏：左侧「缺口与补全」直接填句，右侧「补全文案」生成、下载、审查；顶部保留覆盖度摘要与已覆盖方向；
- 素材扩写独立成页：左侧原始素材，右侧渠道/风格/篇幅，下方正文、饱满度与补全建议；
- 补全文案可直接下载，或点「补全并审查」同步到合规预审并即时显示结果；
- 自适应窄屏；页签化减少单页信息密度；
- 所有用户输入在注入 HTML 前做转义，风险标注由引擎生成。

## 验证

- `python -m py_compile app.py engine.py content.py content_gaps.py compliance.py expander.py` 通过。
- `python -m unittest discover -s tests -v`：20 项回归通过，覆盖合规、方向库、素材扩写、品类场景切换、事实不编造与渠道限制。
- 无头 Edge + CDP 实际走通：素材扩写 → 送去合规预审；扫描内容缺口 → 直接补全 → 生成补全文案；同时渲染六个页签。
